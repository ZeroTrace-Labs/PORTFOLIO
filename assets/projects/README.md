# Project Images

Place project screenshots or photos in this folder, then set the matching project's `image` field in `config/portfolioData.js` to a relative path such as `assets/projects/network-monitor.png`.

Set that project's `githubUrl` to its repository URL to show a direct GitHub button on its card.

`opsmemory-incident-response.png` is a dashboard screenshot from the [OpsMemory AI Incident Response Agent repository](https://github.com/ZeroTrace-Labs/Incidence-Response-AI-agent).

`cybershield-threat-analyzer.png` is the application screenshot from the [CyberShield Phishing & Message Threat Analyzer repository](https://github.com/ZeroTrace-Labs/AI-powered-CyberSecurity-Threat-Analyzer).
