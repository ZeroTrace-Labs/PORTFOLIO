# Security Lab Images

Place lab screenshots or diagrams in this folder, then set the matching `homeLabs` item's `image` field in `config/portfolioData.js` to a relative path such as `assets/labs/wazuh-dashboard.png`. Add an `imageAlt` value describing the image for screen-reader users.

Set its `githubUrl` to the lab repository URL to show a direct GitHub button on the card.

`linux-ssh-threat-analysis.png` is the Splunk dashboard screenshot from the [Linux Log Analyzer repository](https://github.com/ZeroTrace-Labs/Linux-log-Analyzer), displayed on its Security Automation card.

`linux-hardening-audit-output.png` is an example console report from the [Linux Hardening Audit Tool repository](https://github.com/ZeroTrace-Labs/Linux-Hardening-Audit-Tool), displayed on the Linux Security & System Hardening card.
