# Blog Project Images

These images are screenshots for repository-backed project records shown in the Blog section. Keep them limited to genuine project evidence, and provide a descriptive `imageAlt` value.

Project records are configured in `portfolioConfig.blogProjects` in `config/portfolioData.js`; the repository URL is shown as the project link.

Published article text, categories, dates, and references live in `config/blogArticles.js`. Each article's `slug` maps to the shared `article.html?slug=...` page. Add a publication date only when the article is ready to publish.
