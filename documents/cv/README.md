# CV Folder

This folder can store your professional CV PDF.

## Instructions

1. **Upload your CV**: Place your CV PDF file in this folder
2. **File naming**: Name the file `Morgan-Mutugi-CV.pdf`.
3. Update the CV link in `index.html` to point to the PDF when it is available.

## Expected File

- **Filename**: `Morgan-Mutugi-CV.pdf`
- **Format**: PDF
- **Location**: `/documents/cv/Morgan-Mutugi-CV.pdf`

Until a CV PDF is available here, the portfolio asks visitors to request it by email.
